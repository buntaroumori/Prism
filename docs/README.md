## Documentation conventions

Documentation is written in English and describes behaviour that exists in the current source.
Changes to commands, configuration, data formats or public workflows should update the relevant
document in the same change.

`LICENSES.md` is generated by `scripts/license-audit.mjs` and must not be edited directly. Run
`pnpm licenses` after changing dependencies and commit the regenerated inventory.
